# Чат-бот «Помощник студента»

Программа подготовлена в рамках кейса № 3 производственной практики. Чат-бот распознает ключевые слова в вопросах на русском языке и выбирает подходящий ответ из базы намерений.

## Возможности

- приветствие и завершение диалога;
- сведения о сроках, продолжительности и месте практики;
- краткая информация о кейсах и отчетных документах;
- ссылка на репозиторий с программой;
- ответ по умолчанию для неизвестных вопросов.

## Структура

- `chatbot.py` — распознавание намерений и консольный интерфейс;
- `intents.json` — ключевые слова, фразы и ответы;
- `evaluation_cases.json` — набор контрольных фраз;
- `evaluate.py` — расчет точности и времени обработки;
- `test_chatbot.py` — автоматические тесты.

## Запуск

Требуется Python 3.10 или новее.

```bash
python chatbot.py
```

Пример:

```text
Вы: Когда заканчивается практика?
Бот: Практика проходит с 13 января по 23 февраля 2026 года.
```

## Проверка

```bash
python -m unittest -v test_chatbot.py
python evaluate.py
```

Тестовый набор специально содержит разные формулировки и несколько сложных фраз. Это позволяет увидеть не только успешные ответы, но и ограничения простого алгоритма на ключевых словах.
