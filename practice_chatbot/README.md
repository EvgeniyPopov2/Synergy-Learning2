# Чат-бот "Помощник студента"

Программу я сделал для кейса 3 производственной практики. Чат-бот ищет ключевые слова в вопросах на русском языке и выбирает подходящий ответ из файла `intents.json`.

## Возможности

- приветствие и завершение диалога;
- сведения о сроках, продолжительности и месте практики;
- информация о заданиях и отчетных документах;
- ссылка на репозиторий с программой;
- ответ по умолчанию для неизвестных вопросов.

## Структура

- `chatbot.py` - основная логика и консольный интерфейс;
- `intents.json` - ключевые слова, фразы и ответы;
- `evaluation_cases.json` - набор контрольных фраз;
- `evaluate.py` - расчет точности и времени обработки;
- `test_chatbot.py` - автоматические тесты.

## Запуск

Требуется Python 3.10 или новее.

```bash
python chatbot.py
```

Пример:

```text
Вы: Когда заканчивается практика?
Бот: Практика проходит с 13 января по 23 февраля 2026 года.
```

## Проверка

```bash
python -m unittest -v test_chatbot.py
python evaluate.py
```

В контрольном наборе есть 30 фраз. Две из них бот пока распознает неправильно. Это показывает ограничение простого поиска по ключевым словам.
