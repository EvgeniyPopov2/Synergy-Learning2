# Synergy-Learning2

Учебный проект по производственной практике "Технологическая (проектно-технологическая) практика".

Период практики: 13.01.2026 - 23.02.2026.

Место прохождения: Университет "Синергия", кафедра цифровой экономики.

## Проект

В каталоге `practice_chatbot` находится простой чат-бот "Помощник студента". Он отвечает на вопросы о сроках и месте практики, количестве часов, заданиях и отчетных документах.

Проект написан на Python и не требует сторонних библиотек.

```bash
cd practice_chatbot
python chatbot.py
```

Проверка тестов и расчет точности:

```bash
python -m unittest -v test_chatbot.py
python evaluate.py
```
